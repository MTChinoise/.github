# `.github`

Dépôt public de métadonnées pour l’organisation GitHub **MTChinoise**.

## Profil de l’organisation

GitHub affiche le README de l’**Overview** de l’organisation lorsque le dépôt s’appelle **`.github`** (public) et contient le fichier **`profile/README.md`** à la **racine** de ce dépôt ([documentation](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile)).

| Emplacement | Rôle |
| :--- | :--- |
| [`.github/profile/README.md`](.github/profile/README.md) | Contenu éditorial principal (à modifier ici). |
| [`profile/README.md`](profile/README.md) | Lien symbolique vers le fichier ci-dessus — chemin attendu par GitHub. |
| [`.github/profile/assets/`](.github/profile/assets/) | Bandeaux SVG (crème) référencés par le README. |
| [`profile/assets/`](profile/assets/) | Copies des mêmes SVG : lors du rendu depuis `profile/README.md`, les chemins relatifs `assets/…` pointent vers ce dossier. |

## À propos

Ce dépôt ne contient pas le code du site [mariequintin.fr](https://mariequintin.fr/) : il sert de vitrine sur GitHub, alignée sur le message et les informations du cabinet (MTC, Reiki, Guérande).
